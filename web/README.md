# VR 제작킷 웹 콘솔 (Phase B)

기존 마크다운+스크립트 하네스에 **로컬 웹 컨트롤 레이어**를 얹은 것.
웹이 플로우 상태·게이트를 **소유**해서 두 실측 버그(예시 누출 / AI 자체결정)를 구조적으로 막는다.

## 실행

레포 루트의 **`START.bat`** 더블클릭 → 웹 콘솔 기동 + 브라우저 열림 + Claude 실행까지 한 번에.
(수동: 레포 루트에서 `py web/server.py 8787` 후 브라우저에서 `http://127.0.0.1:8787`)

⚠️ `python` 아니라 **`py`** — AGENTS.md 하드룰.

- **표준 라이브러리 전용** — pip 설치 불필요, 어떤 Python 3 에서도 실행.

## 구성

| 파일 | 역할 |
|---|---|
| `server.py` | 로컬 서버 (REST + SSE + 정적 서빙). state.json 소유. |
| `flow.json` | **편집 가능한 플로우 정의** (단계·게이트·엔진). UI ⚙플로우편집에서 수정. |
| `engines.json` | 단계별 선택 가능한 엔진/모델 레지스트리. |
| `examples/*.json` | **격리된 참고 예시** (후삼국 등). 회색 표시, 명시적 클릭으로만 복사. |
| `projects/<id>/state.json` | 프로젝트별 실행 상태. **빈 값에서 시작.** |
| `AGENT_CONTRACT.md` | Claude 계약서 — 값은 state에서만, 스스로 단계 못 올림, 자기 채점 금지. |
| `static/` | 3-pane 대시보드 (좌 플로우 / 중 작업 / 우 문서·실시간). |

## 두 버그가 죽는 방식

1. **예시 누출** → 새 프로젝트 `inputs`는 전부 비어서 시작. 예시는 `examples/`에 격리, "이 예시 값으로 채우기"를 사용자가 눌러야만 유입(로그 남김). 스크립트 하드코딩 경로 제거.
2. **AI 자체결정** → 게이트 통과는 UI 클릭(`POST /gate`)으로만 기록. 필수 입력이 채워져야 게이트 활성화. Claude는 `AGENT_CONTRACT.md`대로 state만 읽고 게이트를 못 넘긴다.

## Claude로 실행 연결하기 (Phase B 사용법)

1. 웹에서 프로젝트 생성 → STEP 1에서 주제·배경 직접 입력 → **확정**.
2. Claude에게: "이 프로젝트의 `web/AGENT_CONTRACT.md`와 `projects/<id>/state.json`을 읽고 현재 단계를 진행해줘."
3. Claude는 게이트 미통과 단계에서 멈추고 "웹에서 확정하세요"라고 안내한다.

## 차후 (범위 밖)

- Tauri(Rust) 패키징으로 .msi 설치본.
