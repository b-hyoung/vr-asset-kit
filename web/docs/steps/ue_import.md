# 4.5 언리얼 임포트

UnrealClaude MCP로 **직접** 임포트·스폰·배치.

## 함정 (실측)
- **저폴리 메시가 Nanite면 렌더에 안 보임** → Nanite 끄기
- glTF 임포트가 base color 미연결 → 임포트 텍스처로 **`M_*_AI` 머티리얼 직접 생성**
- 에디터 백그라운드면 뷰포트 캡처가 stale → SceneCapture2D로 렌더(RTF_RGBA8)

## ⛔ 에디터 크래시 회피 (실측 08-31 — 가장 위험했던 함정)
- **원인 확정(크래시 콜스택)**: UnrealClaude 플러그인이 스크립트 실행 후 **액터 순회 중**, MCP 경유 `load_level`/`new_level`로 **레벨을 전환**하면 무효 월드를 순회 → access violation. **레벨 자체는 정상.**
- **회피책(하드룰)**: **레벨 전환을 하지 않는다.** 에디터를 **작업할 레벨로 네이티브 직접 시작**하고, 이후 **제자리(in-place) 편집만** 한다. import/place/dusk 전 과정에서 `open/new/save_as`로 레벨 갈아타지 말 것.
- **무거운 씬이 크래시를 가중**(별 450+, 볼류메트릭 안개) → 별 개수 축소 + 볼류메트릭 OFF로 안정화.

## 경로·로그 (실측 08-31)
- **임포트 경로를 이전 프로젝트로 하드코딩 금지**(`/Game/Husamguk/` 등) → **이 프로젝트 전용 경로**(예 `/Game/VR_Gyeonhwon/`)로.
- **`ue_exec.py`는 출력 버퍼링 + 긴 로그로 REPORT가 잘림** → 임포트 결과는 **별도 검증 스크립트**로 확인(REPORT 파싱에 의존 말 것).
