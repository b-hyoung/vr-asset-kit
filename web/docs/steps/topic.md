# 2. 주제·배경 입력 → 앵커 선택

**무엇을, 어디 배경으로 만들지**를 사용자가 직접 정한다.

## 규칙 (하드룰)
- 주제·배경은 **반드시 사용자 입으로 확정**한다.
- 이전 세션·문서·예시(후삼국 등)에서 **끌어오기 금지**.
- 확정 전엔 에셋·스타일 어느 것도 미리 정하지 않는다.

> 실측 실패(08-24): AI가 주제를 안 묻고 스스로 잡아 진행함 → 이 게이트로 차단.

---

## 같은 화면에서 앵커까지 정한다

모호한 톤을 **4장으로 분해**해 사용자가 1장 고른다 = 스타일 **앵커**.

## 절차
1. 은은 / 중간 / 뚜렷 / 하이 — 강도 스펙트럼 4장 생성
2. 사용자가 1장 선택 → 이후 모든 에셋의 기준
3. 이미지 엔진은 단계 상단에서 선택 (기본: 로컬 이미지)

> 실측(08-21): 브리프의 "판타지풍"을 AI가 임의 해석 → 스펙트럼으로 사용자가 직접 고르게.

## 배경 참고 이미지를 직접 넣은 경우 ★
사용자가 이미 원하는 배경 그림을 갖고 있으면 **생성을 건너뛰고** 파일을 직접 넣는다.

- **한 장만** 유지된다. 새로 넣으면 이전 것을 교체한다. 고를 것이 없으므로 **넣는 즉시 앵커로 확정**된다.
- `state.ref_images[0]` 에 기록되고 **실제 파일로도 저장**된다: `web/projects/<id>/out/ref_bg.png` (경로는 `.path`)
- 이 그림은 **씬에 합성하지 않는다.** 에셋 리스트업과 배치의 **기준**으로만 쓴다 (`assets.md`, `place.md`).
- 지우면 앵커 확정도 함께 풀린다 — 없는 걸 가리키는 상태를 만들지 않기 위해서다.
