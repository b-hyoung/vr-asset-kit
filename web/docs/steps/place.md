# 5. 자동 배치 루프

배치 → **심판(판정)** → 재배치 반복.

## 규칙
- **AI 자기 채점 금지.** 판정은 사용자 또는 OpenAI 심판.
- `scatter_houses`(2D 산포)는 **1회가 최선** (다회는 과산포).
- 사용자 수동 수정 뒤에는 **assemble 재실행 금지**(다 날아감) — 개별 액터만 손대기.

> 심판 엔진은 단계 상단에서 선택 (OpenAI / Claude / 사용자 수동).

## 구도 다듬기 체크리스트 (실측 08-31)
여러 패스로 나온 구도 결함 → 각 항목을 제자리 편집으로 교정:
- **다리 과대/상자처럼 보임** → 스케일 하향 + 난간·상판 디테일 살리기(밋밋한 큐브 방지).
- **강물이 시점 따라 안 보임** → 수면을 넓히거나 카메라 높이/각 조정(수평선 아래로 안 잠기게).
- **은하수·별이 약함** → 방출/개수 상향, 노출과의 균형(단 별 과다는 크래시 유발 → 적정선).
- **성이 어두움** → 성 쪽 필/스포트라이트 보강(기본 SkyLight는 건드리지 않음).
> 이 단계는 **제자리 편집만**(ue_import의 크래시 회피 하드룰 준수). assemble/레벨전환 재실행 금지.
