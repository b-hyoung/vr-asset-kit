# 3. 에셋 리스트 확정

만들 에셋을 **빠짐없이** 확정한다. 확정 전 제작 시작 금지.

## 절차
1. AI가 앵커와 대조해 **빠진 에셋을 먼저 제안**
2. "부족·빠진 거 있나요?" — 사용자에게 물어 확정
3. 확정 게이트 통과 후에만 제작 시작

> 실측(08-24): 나무·사람/동물·굴뚝연기가 빠졌는데 "완성"이라 착각 → 앵커 대조로 먼저 찾고 확정.

## 에셋 분류 (실측 08-30) — 메시 vs 씬레벨
확정한 에셋을 **두 갈래로 분류**한 뒤 제작:
- **image→3D (프롭)**: 우물·집·다리·성 등 **입체 물체**. `gen_prop_image.py` → Hunyuan3D.
- **씬레벨(비메시)**: 별빛·은하수·강물·안개처럼 **메시로 부적합**한 것 → 3D 생성하지 말고 **언리얼 씬에서 처리**(Niagara/스카이/워터/포스트프로세스).
> 실측: 10개 중 3개(별빛·은하수·강물)가 메시 부적합 → 7개만 image→3D. 분류를 먼저 못 하면 헛생성.

## 배경 참고 이미지가 있으면 ★
`state.ref_images[0].path` 에 사용자가 준 배경 그림이 있으면 **그 파일을 열어서 보고** 리스트를 뽑는다.

- 그림에 **보이는 것**을 근거로 적는다. 안 보이는 걸 상상으로 넣지 마라.
- 그림에는 있는데 리스트에 빠진 것을 **AI가 먼저 짚어 제안한다.** 사용자가 매번 지적하게 두지 않는다.
- 그래도 확정은 사용자다. "빠진 거 있나요?"를 묻고 답을 받은 뒤 게이트.
