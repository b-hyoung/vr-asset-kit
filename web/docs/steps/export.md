# 8. Export (자체완결 GLB)

## 규칙
- **자체완결 GLB로 export** — 메시+텍스처+조명(KHR_lights_punctual) 포함
- USD 레벨 export는 파일을 안 남김 → GLB 사용
- 애플비전 이관: Mac에서 USDZ 변환. 하늘·안개·노출은 안 감

## 에러 없이 내보내기 (절차 — 실측 규칙 반영)
1. **레벨 전환 금지.** 지금 열려 있는 레벨 그대로 export (ue_import의 크래시 회피 하드룰). `open/save_as`로 갈아타지 말 것.
2. export **전에** 대상 액터가 다 있는지 검증 스크립트로 확인(REPORT 로그는 잘릴 수 있음 → 파일/씬 직접 확인).
3. **레벨 전체가 아니라 선택 액터를 GLB로** export(레벨 USD는 파일 안 남음).
4. 출력 경로는 **레포 루트 기준**으로 지정(예 `<repo>/scripts/out/scene.glb`), 폴더 미리 생성.
5. export 후 **파일 존재 + 크기(>0)** 확인. 텍스처/라이트가 GLB에 인라인됐는지 뷰어로 1회 점검.

## 함정
- **씬레벨 요소(별·은하수·안개·강물)는 GLB에 안 감** → 애플비전/타깃에서 별도 재현(문서에 남길 것).
- 노출·톤매핑·하늘은 GLB로 이관 안 됨 → 타깃 앱에서 조정.

> 최종 산출물 확인은 사용자.
