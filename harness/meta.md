# 메타 하네스: 루프 설계 필수 질문

루프를 새로 만들거나 수정할 때, 실행 전에 아래 8개 질문에 전부 답이 있어야 한다.
답이 없는 항목은 진행하지 말고 사용자에게 묻는다. 순서도 지킨다 — 1번이 모든 것에 앞선다.

## 1. 결과물 단위가 무엇인가? (최우선)
에셋 1종인가 / 여러 에셋으로 이뤄진 **장면**인가 / 레벨 전체인가?

⚠️ 기록된 실수 (2026-08-24, 후삼국): AI가 **주제·배경을 사용자에게 안 묻고** 이전 세션/맥락에서 스스로 "후삼국"으로 잡고 진행함.
→ 규칙: 새 세션·새 작업은 **주제·배경부터 사용자 입으로 확정.** 이전과 같을 거라 가정 금지. 확정 전엔 에셋·스타일 미리 정하지 않는다.

⚠️ 기록된 실수 (2026-08-21, 후삼국): 사용자가 "성 밖에서 보이는 마을" 장면을 원했는데
루프를 "단일 에셋 파일럿"으로 축소해서 설계함.
→ 규칙: 결과물이 복합(장면)이면 **반드시 에셋 리스트업부터** 시작한다.

## 2. 리스트업이 먼저다
장면이면: 필요한 에셋을 카테고리별로 리스트업 → 사용자 확정 → 그다음에 루프 설계.
리스트 없이 루프 구조부터 만들지 않는다.

## 3. 각 에셋의 제작 경로와 **표면**이 정해졌는가?
경로: 기성 다운로드(Sketchfab·PolyHaven) / 생성(Hyper3D·Hunyuan3D) / 절차적 모델링 중 하나로 명시.
판단 순서는 `scene-loop.md`의 "에셋 소스 우선순위" — **절차적 모델링은 최후 수단이다.**

**형태만 정하고 끝내지 않는다.** 에셋마다 표면(머티리얼)도 같이 정한다:
다운로드·생성 에셋은 머티리얼이 내장돼 오지만, **절차적 에셋은 표면이 아예 없다.**
환경광(HDRI)도 여기서 정한다 — 조명 없이 머티리얼을 판정하면 전부 다시 봐야 한다.

## 4. 배치 규칙이 두 층으로 있는가?
- **개별 규칙**(범용): 접지, 회전·스케일 지터, 이격, 경사 제한 → `scene-loop.md`
- **구성 규칙**(장면 전용): 상대 배치, 동선, 군집 → 각 프로젝트의 장면 브리프

## 5. 완성 판정이 정의됐는가?
루프가 스스로 멈추는 조건: 수량, 검증 기준, 캡처 각도.

## 6. 실패 경로가 정의됐는가?
재시도 상한(기본 3회), 초과 시 건너뛰고 보고 or 에스컬레이션.

## 7. 대상이 정해졌는가?
어느 프로젝트, 어느 레벨에 실행하는가. 엔진 프로젝트가 아직 없으면 "생성부터"가 답이다.

## 8. 모호어를 분해했는가?
브리프의 형용사·수식어("판타지풍", "소박한", "자연스럽게", "미래적인")는 그대로 두지 않는다.
단어마다 **스펙트럼 4단계로 이미지를 생성해 사용자가 고르게 한다** — 텍스트로 묻지 않는다.
절차는 `templates/ambiguity-probe.md`. 확정된 정의는 장면 브리프에 다시 기록한다.

## 관통 원칙

- **AI 자기 채점 금지.** 합·불 판정은 사용자가 한다.
- **미적 판단은 실물로.** 분위기·강도·톤은 텍스트 질문 대신 이미지 4장을 보여주고 고르게 한다.
- **텍스트 질문은 최소한.** 루프를 돌리는 데 꼭 필요한 것만 묻는다.
- **규칙은 회고에서.** 사전 상상이 아니라 실제로 실패한 것만 규칙이 된다.
