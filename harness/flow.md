# flow — 노드 흐름 & 게이트 & 재시도 루프 (그래프 엔지니어링)

이 하네스는 **루프(DAG) 구조**다. "시작해줘" 이후 **언제 사용자를 찾고(게이트), 언제 다시 만드는지(재시도)** 를 여기 확정한다.
`RUN.md`가 순서를, 이 문서가 **되돌이·게이트 규칙**을 담는다. (후삼국 실주행에서 검증)

## 1. 전체 노드 흐름
```
intake ──► 강도스펙트럼(4장) ──►★앵커확정──► 에셋리스트 ──►★리스트확정
                                                              │  에셋마다 반복 ⟲
                                                              ▼
                    gpt-image 컨셉 ─► Hunyuan3D ─►[Blender 수정·베이크(필요시)]─► import(Nanite off+머티리얼) ─►★validate
                                                              │  전부 passed/skipped 되면
                                                              ▼
                          장면배치 ─► 자동배치루프(OpenAI 독립심판 ⟲) ─► 조명·무드 ─►★최종판정 ─► export
```
★ = **사용자 게이트**(사람이 판정). 나머지 되돌이는 자동 or 독립 심판.

## 2. 사용자 게이트 (★) — 여기서만 멈추고 사용자에게 묻는다
| 게이트 | 무엇을 묻나 | 통과 조건 |
|---|---|---|
| **주제·배경** | "무엇을, 어디 배경으로?" — 스스로 잡지 마라 | 사용자가 말함 |
| **앵커확정** | 강도 스펙트럼 4장 중 하나 고르기 | 선택 = 스타일 앵커 |
| **리스트확정** | "부족·빠진 에셋 있나?" (AI가 앵커 대조로 빠진 것 먼저 제안) | 사용자 확정 |
| **에셋 validate** | 각 에셋 렌더 보여주고 "합격인가" | 사용자 합격 (아래 §4) |
| **최종판정** | 완성 장면 "의도한 장소로 보이나" | 사용자 합격 |
| **파괴적 작업 전** | 기본 에셋/템플릿/레벨 덮어쓰기·삭제 | 사용자 명시 승인 |

> 그 외 **중간 수렴은 사용자에게 안 묻는다** — OpenAI 독립 심판이 자동 판정(§5). R3(자기채점 금지)는 **최종 게이트에만** 적용.

## 3. 재시도 규칙 — "증상 → 되돌이 지점" (제일 싼 되돌이부터)
사유를 그 노드 재료에 **누적(append)** 하고 재실행. **intake로는 되돌아가지 않는다**(요구는 유효, 해석만 틀림).

### 층1 — 에셋 자체 (validate 게이트)
| 증상 | 되돌이 |
|---|---|
| 이미지 형태 뭉개짐·색 이상 | **gpt-image** 재생성 (배제 슬롯에 사유 추가) |
| 3D가 녹음·구멍·블롭 | **Hunyuan3D** 재시도 (다른 컷/시드, 또는 블록아웃-레퍼런스로 형 통제) |
| 비율 틀림(넓적/길쭉) | **concept 이미지** 비율 수정 |
| 폴리 초과·네이밍·단위 위반 | **자동** 감폴리/리네임 (사용자 안 물음) |
| **레퍼런스엔 있는데 없는 요소**(문·창·창살·석축·굴뚝·마루) | **concept/모델링으로 되돌아가 그 요소 추가** |
| 근본적으로 다른 물건 | **concept** 다시 |

### 층2 — 배치·맥락 (장면 게이트)
| 증상 | 되돌이 |
|---|---|
| 겹침·공중부양·파묻힘 | **배치** 재조정 (자동, cmp_openai_scene 액션) |
| 간격 인위적·정렬됨 | **scatter_houses**/지터 (1회가 최선) |
| 옆 것보다 큼/작음 | 그 에셋 **concept(크기)** |
| 한 에셋만 톤 붕 뜸 | 그 에셋 **이미지/텍스처** (앵커 불일치) |
| 마을 전체 톤 어색 | **앵커 재검토**(에스컬레이션 — 사용자) |
| 라이트가 파랑 | 색버그 → `set_light_color(LinearColor)` (재시도 아님, 코드 수정) |

## 4. validate 게이트 = 측정 + 대조 + 판정
1. **객관 측정(자동):** 폴리 예산·텍스처 크기·네이밍·스케일·단일머티리얼. 위반이면 **자동 재시도**.
2. **★레퍼런스 대조(필수):** 앵커를 옆에 놓고 **"거기 있는데 에셋엔 없는 요소"** 를 전부 리스트업 → 하나라도 빠지면 **불통과 → 층1 되돌이**. "박스+텍스처=완성" 착각 금지.
3. **주관 판정(사용자):** 대조 통과 후 형태·미감 합/불.

## 5. 자동 수렴 = OpenAI 독립 심판 (중간 루프)
- 배치 자연스러움: `cmp_openai_scene.py`(gpt-4o) → JSON(score+actions) → 재배치 ⟲ (verdict NATURAL / score≥8 / maxiter)
- 레퍼런스 정합: `cmp_openai.py`(앵커 vs 렌더) → 차이 목록 → 극복 → 재대조 (최대 3회)
- **사용자 개입은 딱 2가지:** (a) 최종 합/불, (b) 심판이 못 잡는 상위 의도("이 날개가 더 길어야") 주입

## 6. 무한루프 방지 — 3중 카운터
- per-asset 큰 되돌이(concept 이상) **≤ 2**
- 경로 전환(절차↔image→3D) **≤ 1**
- 초과 → **스킵**(1급 상태) 또는 **에스컬레이션**(사용자)
- 사유 없는 "불통과"는 재시도 불가 — **사유를 반드시 받는다**

## 7. 스킵 정책
- 스킵은 정상 종료 상태 — 배치 진입 조건 = 모든 에셋 `passed` 또는 `skipped`(무한 대기 방지)
- 스킵 목록을 **최종판정 게이트로 전파** → "빠진 에셋"을 사용자에게 함께 제시
- 앵커 변경 시: 완성된 하류 에셋을 `invalidate`(재작업 대상)
