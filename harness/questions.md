# 질문 시트: 이미지 생성 전 채워야 할 슬롯

규칙: **슬롯이 하나라도 비면 생성 금지.** 슬롯 = 프롬프트의 빈칸.
빈칸이 있으면 모델이 마음대로 채운다 — 그래서 원하는 이미지가 안 나온다.

| # | 슬롯 (프롬프트 자리) | 질문 | 답하는 방법 |
|---|---|---|---|
| 1 | 대상 | 뭘 그리는가 (에셋명/장면명) | 에셋 리스트에서 자동 |
| 2 | 용도 | 3D 변환 입력? 모델링 참고? 분위기 컨펌? | 텍스트 선택 → 구도 규칙 자동 결정 |
| 3 | 시점·구도 | 원경/근경, 3/4시점, 몇 컷 세트 | 텍스트 선택 |
| 4 | 스타일 강도 | 사실적 ↔ 양식화 어디쯤? | ★이미지 보고 선택 (스펙트럼 4장 프로브) |
| 5 | 시간대·분위기 | 낮 / 노을 / 새벽안개 / 밤 | ★이미지 보고 선택 |
| 6 | 필수 요소 | 꼭 보여야 하는 것 | 텍스트 |
| 7 | 배제 요소 | 나오면 안 되는 것 | 텍스트 — **가장 중요한 슬롯** |
| 8 | 스타일 앵커 | 기존 확정 이미지와 톤 맞추기 | 자동 — 첫 확정 이미지가 앵커 |

## 용도별 구도 규칙 (슬롯 2 → 3 자동 결정)

| 용도 | 구도 |
|---|---|
| 3D 변환 입력 | 단일 오브젝트, 정면 또는 3/4 시점, 무지 배경, 그림자 최소, 잘림 없음 |
| 모델링 참고 | 여러 각도 세트(정면·측면·상단), 비율 파악 가능한 구도 |
| 분위기 컨펌 | 장면 전경, 원경, 라이팅·색감 중심 |

## 생성 루프 (슬롯이 다 차면)

```
프롬프트 조립 → 4장 생성 → 사용자가 보고 선택 or 불합격+사유
   → 사유를 배제(7)/필수(6) 슬롯에 반영 → 재생성
   → 최대 3회, 초과 시 중단하고 질문
```

## 앵커 규칙

첫 확정 이미지 = **스타일 앵커.** 이후 모든 생성에 참조로 포함해 장면 전체 톤 일관성 유지.
앵커가 바뀌면 이미 만든 에셋과 어긋나므로, 바꿀 때는 사용자에게 명시적으로 확인한다.

## 배제 슬롯(7)이 가장 중요한 이유

이미지 모델은 학습 분포의 평균으로 끌려간다. "한국 전통 건축"이라고만 쓰면
일본·중국풍 요소가 섞여 나온다. 원하지 않는 것을 **명시적으로 나열**해야 빠진다.
불합격 사유는 거의 전부 이 슬롯으로 환원된다 — 재생성 전에 사유를 7번에 추가하라.
